◆ 02 / THE PROBLEM 02 — 07
The problem

A 5-person studio runs
on seven browser tabs
and one tired founder.

Small creative studios — design, editorial, branding, content — live inside QuickBooks, Harvest, Dropbox Sign, Airtable, and Gmail. None of these tools talk to each other. So the founder does.

  • Contracts get signed in Dropbox Sign   — but the project never lands in Harvest, the client never lands in Airtable, the kickoff email never goes out.
  • Invoices age in QuickBooks   — until someone notices, drafts a polite reminder, and sends it manually.
  • Payments land unapplied   — and sit there, because matching them to invoices is "later this week."
  • Time isn't logged   — until Friday at 6pm.
01 / WHO

1–10 person creative studios.

Founder-led. No ops hire. Already paying for QBO, Harvest, Sign, Airtable, Gmail.

02 / WHY NOW

The "ops tax" is a tax on margins.

Studios in this band leave 4–8 hours per week on glue work — context-switching across tools that should already be cooperating.

03 / WHY NOT JUST HIRE

An ops hire is a $70k decision.

Most studios at this size can't justify it — so the founder absorbs it, badly. The work doesn't disappear; the margin does.

// the gap is between tools, not inside them
◆ 03 / THE SOLUTION 03 — 07
What we built

One ranked inbox.
Agents propose. You approve.

Linkbook ingests events from all five tools, scores them, and surfaces only the ones that need a human. For each one, an agent drafts the concrete next action — and waits for one click.

01 / READ

Cross-tool inbox

QBO, Harvest, Sign, Airtable, Gmail — one ranked feed. No tab-switching.

02 / PROPOSE

Agent drafts the move

Specialized sub-agents per integration. Confidence-scored. Reads the context, drafts the action, surfaces it.

03 / APPROVE

One click, with undo

Approve, edit, or reject. Idempotent dispatch. 24h soft-undo on every action.
